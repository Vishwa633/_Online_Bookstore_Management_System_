Manage books, users, borrow/return operations, authors, admin, and reviews efficiently.

## 📘 About the Project

**Online Bookstore Management System** is a fully functional bookstore management web application that allows admins, users, and authors to manage books, borrow/return operations, reviews, and inventory.  
It is built using **Java** with **file handling** (no database) and demonstrates **OOP principles** like encapsulation, inheritance, polymorphism, and abstraction.

---

## 🚀 Features

- User registration & login system  
- Admin panel to manage books, users, and authors  
- Add, update, delete, search books  
- Borrowing & returning system  
- Author management  
- Review & rating system  
- File-based data storage (users.txt, books.txt, borrowed_books.txt, authors.txt, reviews.txt)  
- Sorting books by price or rating (Quick Sort)  

---

## 🛠 Modules

### 👥 User Roles
- **Admin** – Full control over users, books, authors, and reviews  
- **User/Customer** – Browse, borrow/return books, leave reviews  
- **Author** – Manage book details and view reviews
